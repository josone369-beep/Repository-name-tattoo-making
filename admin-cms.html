사용 가이드

🔑 1단계: GitHub Token 생성

  1. GitHub Settings → Tokens 접속
  2. "Generate new token (classic)" 클릭
  3. Note: Tattoo Making Website
  4. Select scopes: repo 전체 체크 ✅
  5. "Generate token" 클릭 후 복사

💾 2단계: 콘텐츠 편집

  • 📸 이미지 관리: 드래그&드롭으로 포트폴리오/도안 이미지 업로드
  • 📝 텍스트 편집: 타이틀, 설명, About 내용 수정
  • 💰 가격 관리: 모든 가격대 수정
  • ⭐ 후기 관리: 고객 후기 6개 편집
  • 📞 연락처: 전화번호, 카카오톡, 인스타그램 수정

🚀 3단계: 자동 배포

  1. 각 섹션 편집 후 "저장 및 배포" 버튼 클릭
  2. 자동으로 GitHub에 업로드되고 index.html 수정됨
  3. 1~2분 대기 후 사이트 확인
  4. Ctrl + Shift + R로 강력 새로고침

⚠️ 주의사항

  • 🔸 Token은 절대 타인에게 공유하지 마세요
  • 🔸 이미지는 JPG, PNG 형식만 지원 (10MB 이하)
  • 🔸 변경사항은 즉시 적용되지 않습니다 (1~2분 소요)
  • 🔸 여러 항목 동시 수정 후 한 번에 배포 가능
