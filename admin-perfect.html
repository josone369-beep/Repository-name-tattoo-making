🔐 Personal Access Token 생성 방법

1. GitHub → Settings → Developer settings → Personal access tokens

2. "Generate new token (classic)" 클릭

3. Note: TATTOO MAKING CMS

4. Expiration: 90 days

5. repo 전체 체크 (중요!)

6. "Generate token" 클릭 후 토큰 복사
