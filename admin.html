이미지 변경 가이드

📸 1단계: 이미지 업로드하기

  1. ImgBB 사이트 접속: https://imgbb.com/
  2. "Start uploading" 버튼 클릭
  3. 타투 사진 선택 후 업로드
  4. 업로드 완료 후 "Direct link" 복사

🔗 2단계: URL 붙여넣기

  1. 위의 "이미지 관리" 탭으로 이동
  2. 변경할 이미지의 "새 이미지 URL" 입력란에 복사한 링크 붙여넣기
  3. "변경 저장" 버튼 클릭
  4. 생성된 코드 복사

💾 3단계: GitHub에 적용하기

  1. GitHub 리포지터리 접속: 리포지터리 바로가기
  2. index.html 파일 클릭
  3. 연필 아이콘 클릭 (편집)
  4. Ctrl + F로 기존 이미지 URL 찾기
  5. 복사한 새 URL로 교체
  6. "Commit changes" 버튼 클릭 (2번!)

✅ 4단계: 배포 확인

  1. Netlify 배포 페이지 확인: 배포 현황
  2. "Published" 상태 확인 (약 1분 소요)
  3. 사이트 접속: https://amazing-malabi-e1daff.netlify.app/
  4. Ctrl + Shift + R (강력 새로고침)

⚠️ 주의사항

  • 🔸 이미지는 정사각형 비율을 권장합니다
  • 🔸 이미지 크기는 800x800px 이상을 권장합니다
  • 🔸 URL은 반드시 https://로 시작해야 합니다
  • 🔸 변경 후 반드시 강력 새로고침을 해주세요
