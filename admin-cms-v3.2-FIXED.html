✨ 주요 기능

  • ✅ 연락처 자동 배포: 전화, 카카오톡, 인스타그램, 링크트리 정보 변경
  • ✅ 텍스트 자동 배포: 메인 타이틀, 서브타이틀, 설명 수정

🚀 사용 방법

  1. 상단 GitHub Token 설정 입력 및 저장
  2. 원하는 탭 선택 (연락처/텍스트/가격/후기/지도)
  3. 내용 수정
  4. 하단 "연락처 저장 및 배포" 버튼 클릭
  5. 1~2분 대기 후 사이트에서 확인 (Ctrl+Shift+R 강력 새로고침)

  • 🔐 GitHub Token은 repo 권한이 필요합니다
