사용 가이드

✨ v3.1 완전 자동화 기능

  • ✅ 텍스트 자동 배포: 메인 타이틀, 서브타이틀, 설명 자동 수정
  • ✅ 연락처 자동 배포: 전화번호, 카카오톡, 인스타그램 자동 수정
  • ✅ 가격 자동 배포: 4가지 가격대 자동 수정
  • ✅ 후기 자동 배포: 고객 후기 6개 자동 수정
  • ✅ 통합 배포: 버튼 한 번에 모든 변경사항 적용!

📝 사용 방법

  1. 원하는 탭 선택 (텍스트/연락처/가격/후기)
  2. 내용 수정
  3. "모든 변경사항 저장 및 자동 배포" 버튼 클릭
  4. 자동으로 GitHub에 업로드되고 index.html 수정됨
  5. 1~2분 대기 후 사이트에서 확인 (Ctrl+Shift+R)

⚠️ 주의사항

  • 🔸 여러 탭을 수정해도 한 번에 배포됩니다
  • 🔸 배포 중에는 다른 작업하지 마세요
  • 🔸 변경사항 적용까지 1~2분 소요
  • 🔸 반드시 강력 새로고침 (Ctrl+Shift+R) 하세요
